## ✨ Features & Capabilities

- **⚡ 99¢ Doorbreaker Specials & Bargain Catalog**: Filterable inventory of household cleaning goods, Mexican snacks, party supplies, piñatas, kitchenware, and toys. Includes an exclusive **"Under 99¢"** filter with celebratory particle animations.
- **📸 Instagram `@superdiscount.99` Showcase**: Real social feed grid highlighting recent shipment drops, customer favorites, post likes, comments, and direct links to Instagram reels.
- **🗺️ Interactive Store Locator & Hours**: Live store open/closed counter, address lookup, and one-click Google Maps directions.
- **🛒 Store Shopping Planner**: Allows customers to build an in-store checklist, calculate total costs, estimate savings vs. retail prices, and copy/print their list before visiting.
- **🌐 Bilingual Support**: Full English / Español instant language toggle.
- **🔔 Text & IG VIP Club**: Subscription form for local residents to receive weekly deal drops.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/epicenterservices13-spec/superdiscount-vite.git
cd superdiscount-vite
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
